Privacidade

Todos os dados deste aplicativo são armazenados exclusivamente neste dispositivo, em uma base de dados local (IndexedDB). Não há envio de dados para servidores, não há uso de serviços de terceiros, análise de uso (analytics) ou publicidade. Depois de instalado, o aplicativo funciona inteiramente offline.

Sobre

Esta é uma ferramenta pessoal de registro e acompanhamento. Ela não diagnostica, não avalia risco e não recomenda doses ou reduções. Todas as decisões sobre o tratamento devem ser tomadas com acompanhamento profissional.
